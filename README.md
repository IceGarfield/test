# 🎓 위탁교육 결과보고서 자동 작성기 (EduReport)

본 프로젝트는 사용자가 입력한 교육 및 비용 정보를 바탕으로 기업 표준 서식에 부합하는 위탁교육 결과보고서를 실시간으로 시각화하고 PDF로 저장할 수 있게 돕는 웹 애플리케이션입니다.

---

## 🛠️ 설치 방법

본 프로젝트는 별도의 서버 인프라가 필요 없는 **서버리스 정적 웹 애플리케이션**입니다. 별도의 의존성 패키지 설치가 필요 없으며, 소스 코드를 다운로드(클론)한 뒤 브라우저에서 실행할 수 있습니다.

```bash
git clone https://github.com/IceGarfield/test.git
cd test
```

---

## ⚙️ 필요한 환경변수 목록

본 애플리케이션은 보안 강화를 위해 API 키를 서버나 코드에 하드코딩하지 않습니다. 
* **`GEMINI_API_KEY`**: AI 분석(일정표 판독, 영수증 비용 추출, 소감 자동 작성) 기능을 사용하기 위한 Google Gemini API Key입니다.
* **설정 방법**: 웹페이지 실행 후 화면 상단의 **"Gemini API Key 입력"**란에 직접 키 값을 입력하고 디스켓 아이콘(저장)을 누르면 브라우저의 안전한 로컬 스토리지(`localStorage`)에 저장되어 호출 시에만 사용됩니다.

*(로컬 개발환경 템플릿은 `.env.example` 파일을 참조해 `.env` 파일로 작성하여 참고용으로 관리할 수 있습니다.)*

---

## 🚀 실행 명령어 및 실행 방법

### 방법 1. 단순 실행 (더블 클릭)
* 프로젝트 내의 **`index.html`** 파일을 더블 클릭하여 Chrome, Edge, Whale 등의 브라우저로 직접 엽니다.

### 방법 2. 로컬 웹 서버 실행 (권장)
개발자 도구 연동 및 안정적인 로컬 구동을 위해 웹 서버 구동을 권장합니다.

* **Python을 사용하는 경우**:
  ```bash
  python -m http.server 8000
  ```
  이후 브라우저에서 [http://localhost:8000](http://localhost:8000)으로 접속합니다.

* **Node.js (serve 패키지)를 사용하는 경우**:
  ```bash
  npx serve
  ```
  이후 터미널에 표시되는 로컬 웹 서버 주소로 접속합니다.
